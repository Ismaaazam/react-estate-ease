# MERN Real-Estate Platform

A full-stack **MERN web app** with secure authentication, property search, agent contact, and **real-time chat** using **REST APIs** and **Socket.IO**. In testing, we saw an **~40% boost in user interactions** after adding live chat.

---

## 🚀 Features
- 🔐 **User Auth** – JWT-based login/register, protected routes  
- 🔎 **Search** – Filter listings by location, price, type, etc.  
- 📩 **Agent Contact** – Direct in-app messaging with agents  
- 💬 **Real-Time Chat** – Socket.IO chat with typing indicators  
- 🎨 **Responsive UI** – Modern frontend (React + Tailwind/Bootstrap)  
- ⚙️ **Robust Backend** – Express REST API + MongoDB
